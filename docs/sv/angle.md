# Vinkel

Mät en rak yta vid två punkter. Proben återgår till startläget.

<!-- guide-only -->
![Reglage för vinkelmätning](../images/angle.png)
<!-- /guide-only -->

## Välj riktning

**X− / X+** söker i X, med andra punkten längre längs Y+.
**Y− / Y+** söker i Y, med andra punkten längre längs X+.
Börja bredvid ytan på den höjd du vill mäta.

**Z längs X / Z längs Y** probar nedåt två gånger med förflyttning längs X+ eller Y+. Börja ovanför första punkten, högt nog för att gå fri från båda punkterna.

## Avstånd

- **Punktavstånd:** förflyttningen längs ytan mellan punkterna. Större avstånd gör små vinkelskillnader lättare att mäta.
- **Söksträcka:** största söksträckan mot ytan vid varje punkt.

Båda punkterna måste ligga på samma plana yta. Proben backar till sitt startläge före förflyttningen mellan punkterna.

## Resultat

Vinkeln mäts mot maskinaxlarna. Positiv X/Y-vinkel är moturs sett uppifrån. Positiv Z-lutning stiger längs X+ eller Y+.

Med community-firmware kan du välja ett WCS och trycka på **Sätt X/Y-rotation** för att rikta det efter ytan. Nollpunkten ligger kvar. Samma mätning kan användas för ett annat WCS eller öppnas från [historiken](history.md).
