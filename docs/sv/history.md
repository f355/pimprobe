# Historik och loggar

Öppna **Inställningar → Hjälpfunktioner → Probhistorik**. Välj en körning för att se dess mätvärden, inmatade värden, kommandon och eventuella fel.

**Öppna resultat** låter dig använda en sparad mätning för att sätta arbetsnollpunkten. Ämnet och maskinens referens måste fortfarande stämma med mätningen.

## Exportera eller rensa

**Exportera loggar** kopierar historik och diagnostikloggar till en daterad mapp på det monterade USB-minnet. Där ingår kommandon och svar från styrenheten för felsökning.

**Rensa loggar** tar bort sparad historik och loggar efter bekräftelse.
