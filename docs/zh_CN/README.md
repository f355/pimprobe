# 测量指南

选择测量类型：

- [外侧](outside.md)：毛坯边缘、外角或顶面。
- [内侧](inside.md)：型腔侧壁、内角或底面。
- [找中心](center.md)：圆凸台、矩形凸台、孔、型腔、凸棱或凹槽的中心。
- [回转轴](rotary.md)：回转轴心或表面的角度。

按钮上的十字线标出**测球**的起始位置，不是主轴的位置。箭头指向将要触碰的表面，绿点标出测量结果。

## 开始测量

点击图案打开确认页。动画显示移动路径。将路径与毛坯和夹具的位置对照，包括测针的避让空间。

在此修改的距离和进给只用于本次测量。按**开始**时，测量从测球当时的位置开始，因此按下前仍可点动。**取消**返回上一页，不移动机床。

<!-- guide-only -->
![显示移动动画和输入值的确认页](../images/review.png)
<!-- /guide-only -->

测头触碰每个表面两次：先粗测搜索，回退，再慢速精测。精测触碰用于计算测量结果。

[结果与设置工件零点](results.md)

## 坐标与控件

- 大号坐标使用所选工件坐标系；小号坐标使用机床坐标 G53。
- **测头 / 刀具**选择显示测球或刀尖的坐标。刀具坐标使用最后已知的刀长。
- **G54–G59**选择工件坐标系。每个坐标系各自保存零点。
- 页签旁的开关可伸出或收回测头，与测量操作相互独立。
- **?**显示当前页签的说明。

## 触碰与失败

横向和向下的定位移动在测球触碰时停止。点动和普通向上移动不会因触碰而停止。测针碰撞可能不触发测球。

首次搜索未触碰到表面时，测量失败。精测未触碰到表面时，固件可能报警，并使界面返回机床主屏幕。重试前检查搜索距离和起始位置。
