# 角度

在两个测点测量同一直面。测头完成后返回起点。

<!-- guide-only -->
![角度测量控件](../images/angle.png)
<!-- /guide-only -->

## 选择方向

**X− / X+** 沿 X 搜索，第二个测点沿 Y+ 移动。
**Y− / Y+** 沿 Y 搜索，第二个测点沿 X+ 移动。
从表面旁边、需要测量的高度开始。

**Z 沿 X / Z 沿 Y** 向下触碰两次，测点之间沿 X+ 或 Y+ 移动。从第一个测点上方开始，起始高度应能避开两个测点的表面。

## 距离

- **测点间距：** 沿表面在两个测点之间移动的距离。间距越大，越容易测出细微角度差。
- **搜索距离：** 每个测点朝表面的最大搜索行程。

两个测点必须位于同一平面上。在测点之间移动前，测头先退回起始安全位置。

## 结果

角度相对于机床轴测量。从上方看，X/Y 正角度为逆时针；Z 正倾角表示沿 X+ 或 Y+ 升高。

使用社区固件时，选择工件坐标系，按**设置 X/Y 旋转**使其与表面对齐。零点位置保持不变。同一次测量可以应用于另一个工件坐标系，也可以从[历史记录](history.md)中重新打开。
