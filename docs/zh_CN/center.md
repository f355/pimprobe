# 找中心

这些测量触碰相对的表面，求取中点。

<!-- guide-only -->
![找中心测量按钮与距离](../images/center.png)
<!-- /guide-only -->

## 选择测量类型

- **圆凸台 / 孔：**圆形外部 / 内部特征；测量 X 和 Y。
- **矩形凸台 / 型腔：**矩形外部 / 内部特征；测量 X 和 Y。
- **X 凸棱 / X 凹槽：**凸条 / 槽；仅沿 X 横跨测量。
- **Y 凸棱 / Y 凹槽：**凸条 / 槽；仅沿 Y 横跨测量。
- **Z：**向下触碰表面，再返回起始 Z。**深度**设置最大搜索距离。

X 和 Y 表示**横跨**特征的方向，不是其长度方向。

## 圆凸台、矩形凸台或凸棱

从特征上方大致居中的位置开始。起始 Z 必须能在横跨时避开该特征。

**X/Y 搜索距离**是从起点向外移至各侧的距离，不是特征宽度。距离应足以使整个测球越过两侧边缘。**深度**是从起始 Z 下降至侧面触碰高度的距离，包括毛坯上方的间隙。

测头在各侧外部下降，再向内触碰。横跨至另一侧前，先升至起始 Z。测量后，测头停在中心上方的起始 Z 高度。

## 孔、型腔或凹槽

从开口内大致居中的位置开始，处于测量 Z 高度。**X/Y 搜索距离**是从起点向任一侧壁移动的最大距离。数值为 20 时，可搜索至起始坐标 −20 和 +20，而不是总宽度为 20。

测头在此高度横跨两侧壁之间，因此路径必须畅通。不使用**深度**。测量后停在测得的中心，不抬升 Z。

## 测量结果

双轴测量先测 X，移至 X 中心，再测 Y。凸棱和凹槽只将测量轴移至中心。

结果显示矩形凸台/型腔的宽度和长度、凸棱/凹槽的宽度，以及圆凸台/孔各自的 X/Y 跨距。这些数值已包含测球半径补偿。圆形特征的起点偏离中心时，首次测得的 X 跨距可能偏小；需要从居中位置测量直径时，从中心再测一次。
