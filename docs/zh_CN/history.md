# 测量记录与日志

打开**设置 → 辅助功能 → 测量记录**。选择一次测量，查看测量值、输入值、指令和错误。

**打开结果**可用已保存的测量设置工件零点。毛坯和机床坐标基准必须仍与测量时一致。

## 导出或清除

**导出日志**将测量记录和诊断日志复制到已挂载 USB 存储设备上按日期命名的文件夹中。日志包含指令和控制器回复，供排查问题使用。

**清除日志**经确认后删除已保存的测量记录和日志。

## 恢复标定

1. 选择一条**测头标定**记录。**先前值**是修改前的值，**保存值**是本次请求保存的值。
2. 按**恢复先前标定**并确认。
3. 重新测量基准，核对结果。

此操作恢复测球直径和 X/Y/Z 偏移，不改变工件零点。恢复也会生成记录，因此还可以撤销恢复。中断或失败的标定仍保留先前值。**清除日志**也会删除这些标定备份。
