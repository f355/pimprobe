# 内侧

四个侧边图案用于测量内部侧壁，四个角图案用于测量 X 和 Y。中间图案用于测量底面。

<!-- guide-only -->
![内侧测量按钮与距离](../images/inside.png)
<!-- /guide-only -->

## 侧壁或角

将测球放在开口内，处于所需的侧壁触碰高度。

**X 搜索距离**和**Y 搜索距离**是测球从起点向各侧壁移动的最大距离。距离应足以到达侧壁。角测量使用两个距离；单个侧壁只使用该轴的距离。

测量角时：

1. 触碰 X 侧壁。
2. 返回起始 X。
3. 触碰 Y 侧壁。

这些移动均保持起始 Z；不使用**深度**。

![内角：触碰 X，返回起点，再触碰 Y](../images/inside.svg)

测头最终返回起始 X/Y 和 Z。

## 底面

将测球放在底面上方。**深度**是从该位置向下搜索的最大距离。测量后，测头返回起始 Z。

## 移至测得点上方

结果页中的**移至测得的 XY**先按**Z 安全抬升**抬升测球，再移至测得的侧壁或角上方。抬升量应足以避开型腔顶部和路径上的夹具。这是从当前 Z 向上移动的距离，不是绝对高度。
