# 结果与工件零点

大号坐标是测得表面或中心的**G53**坐标。小号坐标显示同一点在所选**G54–G59**中的坐标。测头标定和测球半径补偿已应用。

## 设置工件零点

在**工件零点**旁选择工件坐标系，按需输入偏移，再按**设置工件零点**。只更改已测量的轴。机床不移动。

各轴的新零点为**测得的 G53 坐标 + 偏移**。例如，测得 Z 为 25，输入 −2，则 Z0 位于 G53 Z23。

可以调整偏移后再次设置零点，也可以选择其他工件坐标系，用同一测量结果设置零点。

## 定位按钮

- **返回起点：**先将 X/Y 移至保存的起点，再移动 Z。外侧和找中心结果提供此按钮。
- **移至测得的 XY：**在内侧侧壁/角结果中，先按**Z 安全抬升**抬升，再将测球移至测得点上方。抬升量相对于当前 Z。
- **关闭：**退出结果页，不移动机床。

这些目标位置定位的是**测球**，不是主轴。仅测量 Z 的操作已返回起点。

## 保存的测量

打开**设置 → 辅助功能 → 测量记录**，选择一条测量，再按**打开结果**。只要毛坯和机床坐标基准仍未变化，就可以稍后用它设置工件零点。
